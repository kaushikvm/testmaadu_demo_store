Frequently asked questions

Is this a real shop?

No. OnlineMart is a demo store for practising functional, end-to-end and API testing. Nothing is shipped and no money is charged.

How do I sign in?

Use demo@testmaadu.in with password Demo@123, or any email address with a password of at least 6 characters.

Which card number can I use?

Any 16 digit number works, for example 4111 1111 1111 1111, with any future expiry date and any 3 digit CVV.

Are there coupons?

Yes. TESTMAADU10 gives 10% off and FREESHIP removes the delivery charge.

Is there an API?

Yes. Every page talks to a small REST API under /api. See the API docs or download openapi.json.

Why did my orders disappear?

The demo server keeps orders in memory, so they can reset when the server restarts. Your browser also keeps a copy, so My orders still shows them on this device.

Terms and conditions

This store is for demonstration only. By placing an order you agree that no goods will be delivered, no payment will be taken, and data you enter may be reset at any time. Please do not enter real card numbers or personal data.
